# PlanetX 后半段增长与变现闭环重设计

> 文档用途：供团队学习 PlanetX 当前"闯关完成后体验断裂"的问题诊断，以及"游戏化冷启动 → 邮箱注册增长 → 订阅变现"的后半段衔接方案。
> 整理日期：2026-08-08
> 设计立场：用游戏包装职业成长的冷启动，不是"测人格拿称号"的小游戏。

---

## 0. 一句话定位

PlanetX 不是测人格拿称号的玩具，而是**用太空叙事让求职者完成"你是谁、和谁共事过、被谁验证过"的可验证职业成长**。通关后的核心不是"领 XP"，而是"你的行为开始被别人看见，并因此获得更好的职业机会"。

---

## 1. 当前问题：闭环断在哪

截图典型现象：4 项任务完成、200 XP 满格，但"信号传播 0"，也没有下一步必须去做的事。

| 应有环节 | 现状 |
|---|---|
| 闯关产行为 | ✅ 四项任务可跑通 |
| 行为进时间线 | 🟡 入口有了，但签到/记项目不是刚需 |
| 假设随行为更新 | ❌ 人格标签基本静态 |
| 分享 → 回流 → 传播计数 | ❌ 复制文案但"信号传播"仍是 0 |
| C 端档案 → B 端可用 | ❌ 增长漏斗后半段待阶段三落地 |
| 通关后下一动机 | ❌ 没有"全部完成"大奖，无强制下一关 |

**结论**：表达层（星际闯关）已完成，价值层（行为信任闭环）还没落地。漏斗前半段（获客/激活）搭好了，后半段（沉淀→验证→被看见→再回来）没接上。

---

## 2. 设计原则（Design Pillars）

1. **行为即信用**：每个游戏动作必须对应真实职业信号。
2. **被看见才有价值**：行为必须进入可被他人/算法读取的档案。
3. **信任是网络效应**：需要他人验证/共在/传播，而非单人刷分。
4. **闭环制造下一动机**：每个终点都是下一个系统的钥匙，不是结算页。

---

## 3. 断裂的核心循环（三层钩子）

| 循环层 | 应该发生什么 | 截图里实际发生 | 断裂信号 |
|---|---|---|---|
| Moment-to-moment（0-30s） | 任务完成 → 经验条涨 → 触发升级/解锁 | XP 200/200 满格，只显示"满" | 无升级事件、无新系统解锁 |
| Session loop（5-30min） | 一关结束 → 看到下一关入口或通关大奖 | "文案已复制" + 信号传播 0 | 分享没连上计数，无通关大奖 |
| Long-term（days-weeks） | 行为 → 时间线 → 标签更新 → 信任档案 → 匹配 | 时间线只是入口，标签仍是"初始假设" | 行为没变成可验证的信用资产 |

---

## 4. 后半段漏斗：把订阅变成"星舰升级"

目标：通过邮箱注册实现群体增长，再转化为美元订阅。

| 阶段 | 玩家状态 | 游戏化动作 | 订阅触点 | 设计原则 |
|---|---|---|---|---|
| 0. 外部流量 | 看到测评/内容 | 免费人格测评 + 职业标签 | 注册邮箱后才能看结果 | 先给诱饵，再要邮箱 |
| 1. 新兵营 | 完成 4 任务 → Lv.2 | 任务→XP→解锁"匹配预览" | **无付费弹窗** | 免费功能足够建立信任 |
| 2. 价值预演 | 想看清匹配/职位 | 解锁 3 个模糊匹配 + 档案浏览模拟 | 完整档案需要支持者/专业版 | 让玩家尝到甜头 |
| 3. 能力边界 | 想继续用 AI/解析 | 对话次数/解析次数接近上限 | 软性提示"能量不足，升级星舰" | 限制在价值节点，不惩罚 |
| 4. 转化/裂变 | 犹豫是否付费 | 订阅解锁完整功能；或邀请好友换会员 | 明确价值交换：花钱 or 花时间 | 给两条路，别逼单 |
| 5. 长期留存 | 已订阅 | 标签更新、匹配推荐、档案被浏览反馈 | 专业版数据分析 | 让付费者看到 ROI |

**核心判断**：后半段不能是"闯关→弹订阅"，必须是"闯关→价值预演→能力边界→订阅解锁"。200 XP 满格是玩家刚完成情感投入的临界点，此时他最愿意相信"这个游戏对我有用"，要立刻给他看"有什么用"，再把完整功能变成升级钥匙。

## 5. 订阅档位与游戏化包装

| 档位 | 星舰包装 | 解锁能力 | 对应游戏化节点 |
|---|---|---|---|
| **免费版 $0** | 探索艇 | 30 次 AI 对话/日、基础匹配、3 次简历解析 | 新兵营 + 价值预演 |
| **支持者版 $1.99** | 护卫舰 | 100 次对话、高级匹配、无限解析、支持者徽章 | 低门槛转化，学生/新人 |
| **专业版 $5.99** | 巡洋舰 | 无限对话、完整匹配、高级数据分析、优先客服 | 深度用户，匹配需求强 |
| **企业版** | 母舰 | 团队/批量/HR 接口 | B 端，不直接卖给 C 端 |

$1.99 解决"用着不爽"，$5.99 解决"我要更快找到好工作"。

## 6. 五个关键衔接机制

### 6.1 闯关后立刻解锁"匹配预览"
"你的星际信号已发出，3 个可能与你共航的舰队正在附近。"
- 免费用户：只能看模糊头像、公司类型、标签摘要
- 付费用户：解锁完整档案、联系方式、匹配度解析
- **最强转化触点**：玩家刚完成闯关，情绪最高点，且看到了具体价值。

### 6.2 把次数限制包装成"星际能量/扫描仪"
- AI 对话：不叫"30 次"，叫"今日星际能量储备"
- 简历解析：不叫"3 次"，叫"星舰扫描仪次数"
- 接近上限时提示："能量储备不足，今日还剩 5 次，建议补充燃料"
- 点击跳转订阅页，**不要弹硬墙**。

### 6.3 信号传播从虚荣指标变成可兑换货币
- 每 1 位通过你分享链接完成邮箱注册的好友 = **7 天支持者版** 或 **100 XP**
- 信号传播计数不再只是"0→1"的装饰，而是玩家能看到的"社交货币余额"
- 同时解决：裂变增长 + 付费转化前置体验

### 6.4 时间线/档案的"被看见"反馈
- 免费用户可以记录经历，但**只有支持者/专业版才能让经历进入"对外展示"状态**
- 给所有用户看模拟数据："你的档案本周被浏览 12 次"
- 点击"看谁浏览了你"：提示需要升级

### 6.5 邮件激活序列：D3-D7 是转化黄金期

| 天数 | 邮件主题 | 内容 |
|---|---|---|
| D0 | 你的星际人格报告 | 欢迎 + 测评结果 + 首任务 |
| D1 | 完成首个任务，解锁星舰日志 | 任务引导 + 进度反馈 |
| D3 | 你离完整匹配只差一步 | 闯关进度 + 匹配预览预告 |
| D7 | 你的信号被 X 人接收 | 浏览/认可反馈 + 订阅优惠 |
| D14 | 限时：邀请 2 人得 1 个月会员 | 裂变 or 限时折扣 |

## 6.6 答题环节升级（对标 Pymetrics / P1 微任务）

### 6.6.1 问题定位
当前人格冷启动是 8 道四选一自陈问卷（`shared-core/constants/quiz.ts`），前端累计 trait → `computePersonality` 取 top2 → 6 个星际人格标签。UI 是太空皮肤问卷，本质仍是自陈。对标 Pymetrics（~12 个神经科学小游戏做行为观测，输出 91 特质），落差在主落差而非 UI：

| 对比轴 | Pymetrics | PlanetX 现状 | 落差 |
|---|---|---|---|
| 信号类型 | 行为观测 | 自陈选择 | 主落差 |
| 伪装成本 | 高（难装反应时/风险曲线） | 低（会选"好看"选项） | 大 |
| 数据密度 | 单局上千点级行为 | 8 个离散选项 | 大 |
| 输出粒度 | 多维特质向量 | 1 个标签 + 文案 traits | 大 |
| B 端可用性 | 岗位拟合筛人 | 仅域内互补规则 | 中 |

结论：若只把按钮做成小游戏皮、分数仍来自自陈，那是皮肤升级，不是对标升级。需把"自陈"升级为"可观测行为"，并接上多方验证。

### 6.6.2 P1 选型：风险气球 + 信任博弈

| 候选微任务 | 行为观测纯度 | 与定位咬合度 | 退化成自陈风险 |
|---|---|---|---|
| 风险气球（BART） | 极高 | 中（风险取向是职业核心变量） | 低 |
| 信任博弈（Money Exchange） | 极高 | 高（对应"信任网络/舰队共在"） | 低 |
| 情绪识别（Faces） | 中（有正确脸基准） | 低 | 高 |

选型逻辑：风险气球测"你是谁"（个人风险/决策），信任博弈测"你怎么和别人共事"（协作/信任），覆盖 Manifesto 两端，且都 30-60 秒跑完、几乎无法伪装。情绪识别留后，因依赖标准答案且易退化为自陈。

**微任务 A：信号燃料泵（BART 改编）**
- Purpose：观测风险取向与冲动控制，难伪装。
- Player experience：泵气球攒燃料，爆了归零——在"再泵一次"的贪念里暴露风险曲线。
- Inputs：点击/空格泵气；cash out 按钮。
- Outputs：平均泵数、爆裂率、总累积燃料 → `risk_index 0-100`。
- Edge cases：连点（设最小间隔 + 异常检测）；中途退出（保存已得燃料）。
- Failure states：规则不理解 → 加 1 轮演练；爆裂率异常（<5% 或 >80%）→ 标 `low_confidence`。

**微任务 B：舰队补给分配（Money Exchange 改编）**
- Purpose：观测信任与公平倾向——B 端（HR）极看重的协作信号。
- Player experience：你拿到 100 单位补给，决定分给匿名队友多少；队友回报未知。
- Inputs：滑块分配 0-100。
- Outputs：给出比例、是否留底 → `trust_index 0-100`。
- Edge cases：全给/全留极端值 → 标记 `extreme`；误读为"越多越好" → 文案强化"回报随机"。
- Failure states：理解偏差 → 加示例气泡。

### 6.6.3 输出形态：双轨，而非二选一
否决两个单选项：
- 另存 91 维认知向量：Pymetrics 的 B 端电池路线，需常模/公平性/合规，是另一条产品线；冲淡冷启动轻量体验。
- 只修正假设：用行为信号微调 6 标签，证据被稀释进文案；玩家困惑"我选了艺术家，为什么行为说我是冒险家"。

**双轨（采用）**：
- 主轨：现有 6 星际标签保持"初始假设"（自陈），标注"基于你的选择"，不动。
- 新增：行为信号层 `risk_index` / `trust_index` 作为独立字段写入 profile + 时间线。
- UI 明确分区：「你的自述画像」vs「你的行为信号」。
- 好处：诚实（不宣称神经科学）、行为证据保留、为 P2 多方验证加持行为层留接口。

### 6.6.4 数值与接口（含 PLACEHOLDER）

| 变量 | 数值 | 状态 |
|---|---|---|
| 风险气球轮数 | 20-30 轮 | [PLACEHOLDER] · 需验证多少轮后 risk_index 稳定 |
| 单轮泵上限 | 无硬上限，爆点随机 | [PLACEHOLDER] · 爆点分布参数需校准 |
| 信任博弈轮数 | 1-3 轮 | [PLACEHOLDER] · 单轮是否足够观测 |
| 冷启动总增量时长 | +90 秒 | [PLACEHOLDER] · 当前自陈约 2-3 分钟，加微任务后是否超 5 分钟红线 |
| 行为证据字段 | risk_index, trust_index | rationale：独立存储，不被标签稀释 |
| 低信度标记 | 爆裂率 <5% 或 >80% | rationale：异常值意味误操作或刻意 |

接口改动：在 `profile-sync` 回写结构新增 `behavioral_signals` 子对象；时间线新增"行为信号已记录"条目类型，显示 `risk_index` / `trust_index`，与问卷标签视觉区分。

### 6.6.5 如何接回漏斗
- P0 诚实文案：6 标签标"初始假设 · 基于你的选择"；微任务标"行为信号 · 基于你的实际反应"。
- P1 行为证据：上述双轨，写入时间线。
- P2 标签可变：未来舰队验证 / 匹配共识可加持行为信号层，而非粗暴覆盖自陈标签——「随行为更新」真正兑现。
- P3 独立电池：若要对标招聘筛人，单独立"认知电池"产品，不绑死 PlanetX 增长漏斗。

## 11. T空间正式层设计（生成信任 → 呈现信任的闭环收口）

> 回应第 10 章开放问题 2（企业版 / T-space 接口）。T空间是 PlanetX 游戏化数据的正式呈现层，与后半段漏斗（第 4-6 章）、答题升级（第 6.6 章）共同构成"生成信任 → 呈现信任"完整闭环：冷启动玩出行为 → 行为沉淀为证据 → 证据翻译成 B 端语言 → 亮出验证链促成职业机会。

### 11.1 定位：PlanetX 数据的"成年形态"
T空间不是另一个产品，而是 PlanetX 行为证据的正式呈现层。游戏化负责"让行为被生成"（低摩擦参与），T空间负责"让行为被取信"（B 端看得懂、信得过）。核心架构：**一个内核（行为证据 + 验证链 + 时间线），两种皮肤（C 端星际叙事 / B 端职业档案）**。

### 11.2 为什么必须正式

| 维度 | PlanetX（C 端） | T空间（B 端 / 对外） |
|---|---|---|
| 目标 | 降低冷启动摩擦、持续参与 | 让第三方快速建立信任、做决策 |
| 语域 | 星际叙事、游戏奖励 | 职业语言、可核验证据 |
| 可信来源 | 自我探索的趣味 | 别人验证过的事实 |
| 游戏化作用 | 加分（降低门槛） | 减分（显得不专业） |

游戏皮肤在 C 端是诱饵，在 B 端是噪音。HR 看到"星云艺术家 · Lv.2 星际新兵"会本能质疑信度，但看到"创意探索型 · 3 位前同事验证过项目协作"会认真看。

### 11.3 一个内核，两种皮肤

| 数据元素 | PlanetX C 端呈现 | T空间 B 端呈现 | 进 T空间？ |
|---|---|---|---|
| 星际人格标签 | 星云艺术家（太空皮） | 职业特质画像 | ✅ 经翻译层 |
| 行为信号 risk_index | 信号燃料风险指数 | 风险决策倾向（量化分位） | ✅ 更名保留 |
| 行为信号 trust_index | 舰队补给信任度 | 协作信任倾向 | ✅ 更名保留 |
| 时间线 | 星舰日志 | 职业经历时间线（带验证标记） | ✅ 脱敏保留 |
| 验证记录 | 舰队认可 | 同事/上级验证标记 | ✅ 核心资产 |
| 等级 / XP | Lv.2 星际新兵 | —— | ❌ 不进 |
| 舰队皮肤 / 徽章 | 护卫舰皮肤 | —— | ❌ 不进 |
| 信号传播计数 | 社交货币余额 | —— | ❌ 不进 |

**内核**：行为证据（behavioral_signals）+ 验证链（谁验证过）+ 时间线。**皮肤**：C 端套星际叙事，B 端套职业档案模板。同一份 JSON，两套渲染。

### 11.4 翻译层是关键决策
T空间不是简单"去掉 emoji"，而是语义翻译：

| C 端术语 | B 端翻译 | 说明 |
|---|---|---|
| 星云艺术家 | 创意探索型 | 保留特质内核，换职业语域 |
| 信号燃料风险指数 | 风险决策倾向（分位） | 量化、去游戏化命名 |
| 舰队补给信任度 | 协作信任倾向 | 同上 |
| 星舰日志 | 职业经历时间线 | 结构不变，叙事剥离 |

翻译规则需明确定义，避免"C 端说我冒险家、B 端简历写我稳健"的割裂。**翻译层应可配置**，由产品/HR 共建映射表，而非硬编码。

### 11.5 必须保留的内核：验证链
这是 PlanetX 相对传统简历的**唯一真正差异点**，两端都不能丢：
- C 端：舰队认可（游戏化社交验证）
- T空间：同事/上级验证标记（职业化验证）

"被谁验证过"是信任的硬通货。简历谁都会写"沟通能力强"，但"3 位前队友确认过跨团队协调"才是 B 端想要的。T空间要把验证链做成视觉焦点，而非附属信息。

### 11.6 张力：C 端与 B 端不能彻底割裂
- **割裂风险**：C 端玩得很嗨产出一堆行为数据，B 端突然变正经，用户觉得"这还是我吗？"
- **解法**：T空间保留"来自 PlanetX 行为沉淀"的来源标注，让用户感到这是自己玩出来的成果，而非编造的简历。验证链在两端一致，是连接的锚点。

### 11.7 边界与 PLACEHOLDER

| 决策点 | 立场 | 状态 |
|---|---|---|
| T空间可见性控制权 | 求职者可控（选哪些展示给 HR） | rationale：避免被迫全裸 |
| 翻译层映射 | 产品/HR 共建可配置表 | [PLACEHOLDER] · 需定义 6 标签 → 职业特质的具体映射 |
| 哪些游戏元素进 T空间 | 行为证据+验证+时间线进；XP/皮肤不进 | 已定 |
| 验证链视觉权重 | T空间首要位置 | [PLACEHOLDER] · 需 A/B 验证 HR 关注度 |

**闭环收口**：第 4-6 章让玩家"玩出行为并被看见" → 第 6.6 章把自陈升级为"可观测行为证据" → 第 11 章把行为证据翻译成 B 端语言并亮出验证链。至此，"你是谁、和谁共事过、被谁验证过"在 C 端生成、在 T空间呈现，闭环完成。
